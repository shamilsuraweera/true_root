# True Root API

NestJS 12 + TypeORM 1 + PostgreSQL REST API for the True Root app.

- Requires **Node 22.12+** and **PostgreSQL 14+**.
- Setup, environment variables and database creation: [../../docs/SETUP.md](../../docs/SETUP.md)
- Running and scripts: [../../docs/RUNNING.md](../../docs/RUNNING.md)
- Endpoints: [../../docs/API.md](../../docs/API.md)
- Deployment: [../../docs/DEPLOYMENT.md](../../docs/DEPLOYMENT.md)

```bash
npm ci
npm run start:dev      # http://localhost:3000  (GET /health)
npm test               # unit tests
npm run lint
```
